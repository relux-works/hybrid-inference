### F1 - major: response backpressure blocks admission

Fixed in `tools/hybrid/prefill.cpp`. Binary response admission uses two unfinished responses per client and three globally, across four HTTP workers. Both deltas and snapshots acquire a permit before inference or snapshot construction. Excess requests return `429`, `Retry-After: 1`, and `{"error":"binary response limit"}` without changing the session. A response owns its permit until completion or disconnect; exception paths release an untransferred permit through RAII. Connections close after one HTTP/1.1 response so idle keepalive cannot retain the reserved worker. The existing compute scheduler still rotates clients and preserves session FIFO.

It passes in the same log. Concurrent valid requests in the original isolation suite use bounded retries for the new explicit 429 response; their counts and hashes remain asserted.
